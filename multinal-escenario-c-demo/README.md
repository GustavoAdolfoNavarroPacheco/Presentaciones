# Multinal S.A.S. — Demo Interactiva · Escenario C

App demo de 3 apartados (Presentación · Simulador Interactivo · Panel de
Movimientos). El apartado **Presentación** trae las **26 láminas del
Escenario C** (`presentaciones/multinal-escenario-c/`) insertadas con su
propio diseño. Simulador y Panel muestran el prototipo funcional de la
plataforma empresarial propia (ERP + WMS + CRM ampliado).

Es la base original de la que se duplicó `multinal-escenario-b-demo/`
(reemplazando solo el apartado Presentación por el deck de 19 láminas del
Escenario B) y, más tarde, `multinal-escenario-demo/` (fork solo-simulador
para el link público, ver ese README).

Ejecutar localmente: `npx serve docs` (ver `.claude/launch.json`).
